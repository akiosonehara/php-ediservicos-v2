Sistema de Controle de Transferência de Arquivos

Este sistema permite o controle e gerenciamento de serviços de transferência de arquivos para os principais protocolos:

  • SCP (Secure Copy Protocol): Transferência segura de arquivos via SSH
  • FTP (File Transfer Protocol): Protocolo padrão para transferência de arquivos
  • Connect:Direct (CD): Solução IBM para transferência segura de arquivos
  • HTTP: Transferência via protocolo web
  • S3: Armazenamento em nuvem Amazon S3
  • JASPPION: Envio de pagamentos online ao Mainframe

O sistema oferece controle completo de usuários, auditoria de operações e gerenciamento de perfis de transferência.
