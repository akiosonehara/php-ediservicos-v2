Ajuda - SCP
Secure Copy Protocol (SCP)

O SCP é um protocolo de rede usado para transferir arquivos de forma segura entre hosts em uma rede.

Campos Obrigatórios:
  • Perfil: Perfil que deve ter SCP habilitado
  • Servidor: Endereço do servidor SCP
  • Usuário: Nome de usuário para autenticação
  • Porta: Padrão 22 (SSH)
Autenticação:
  • Senha: Autenticação por senha
  • SSH: Chave privada SSH para autenticação sem senha
Opções de Transferência:
  • ZIP: Compactar arquivo antes da transferência
  • CRLF: Conversão de quebras de linha
  • REL: Usar modo relativo
  • BIN: Modo binário
  • DMZ: Transferência via DMZ
  • CODE: Codificação especial
